# Essentia 3D
Progetto open‑source dedicato alla fabbricazione digitale, alle CNC, alla stampa 3D e ai laser cutter.
Un punto di riferimento per maker, studenti, hobbisti e appassionati di automazione.

Essentia 3D nasce per raccogliere guide, file tecnici, tutorial, modelli CAD, G‑code
e tutto ciò che serve per imparare, costruire e migliorare macchine e strumenti digitali.

---

## Obiettivi del progetto
- Condividere conoscenza tecnica in modo semplice e accessibile  
- Creare una base di file e documentazione per workshop e corsi  
- Mostrare la differenza tra soluzioni hobbistiche e professionali  
- Offrire esempi reali di CNC, laser, stampa 3D e automazione  
- Promuovere la cultura maker e l’open‑source

---

## Struttura del repository

### docs/
Documentazione tecnica, schemi, manuali, note di progetto, procedure e tutto ciò che serve per capire come funziona una macchina o un workflow.

### tutorials/
Guide passo‑passo, esercizi, workflow CAD→CAM→CNC, esempi di G‑code commentati, materiale didattico per workshop.

### cad/
Modelli 3D, tavole tecniche, file STEP, STL, DXF, e tutto ciò che riguarda la progettazione meccanica.

### cnc/
Configurazioni GRBL, macro, G‑code di test, firmware, modelli macchina per simulatori come GRBLGRU.

### laser/
Profili LaserGRBL, parametri materiali, SVG, G‑code di prova, note di sicurezza e setup per laser cutter.

### 3dprinting/
Profili di slicing, modelli STL, test di qualità, note sui materiali (PLA, PETG, ASA…), esempi di stampa.

### varie/
Appunti, bozze, idee, mockup del logo, file temporanei e tutto ciò che non ha ancora una categoria.

## Contributi
Essentia 3D è un progetto aperto: chiunque può proporre miglioramenti, aggiungere file, correggere errori o condividere esperienze.

Per contribuire:
1. fai un fork del repository  
2. crea una branch  
3. aggiungi o modifica i file  
4. apri una pull request
